# COVID-19 Data Analysis

## Project Overview
This project analyzes COVID-19 data to identify trends,
patterns and important insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Analysis
- Confirmed cases analysis
- Deaths analysis
- Recovery analysis
- State-wise analysis
- Time-series analysis

## Dataset
Dataset used for this project is included in the data folder.

## How to Run
Open the Jupyter Notebook in Google Colab.

## Results
The project provides visualizations and insights
based on the analyzed data.
